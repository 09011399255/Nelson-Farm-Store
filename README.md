# Nelson Farms Store

Official web platform for **Nelson Farms Store** — a premier bio-secure livestock and agricultural enterprise specializing in natural poultry, piggery, heritage turkey, and aquaculture.

## 🌾 Features

- **Modern Responsive Design**: Built with React 18, Vite, and Tailwind CSS.
- **Divisions Showcase**: Dedicated sections for Chicken & Poultry, Piggery, Turkey, and Fishery.
- **Interactive Price Calculator & Inquiries**: Easy order estimations and instant WhatsApp/modal contact.
- **Biosecurity & Standards**: Highlighting humane animal welfare, selective genetics, and clean nutrition.
- **Fast & Lightweight**: Zero external runtime bloat with optimized asset delivery.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (version 18+ recommended)
- `npm` or `yarn`

### Installation

```bash
# Clone the repository
git clone https://github.com/09011399255/Nelson-Farm-Store.git

# Navigate to project directory
cd Nelson-Farm-Store

# Install dependencies
npm install

# Start local development server
npm run dev
```

### Production Build

```bash
npm run build
```

The production assets will be generated in the `dist/` directory.
